# 需求规格书 · V12 发动机可交互拆解模型

> 本文件是项目的**原始规格书**，逐条实现，技术内容未作改动。原文由需求方给出，仅把开头的角色设定改写为项目目标。
> 文中「数字即法律」指机械规格必须精确照此建模，不是可调参数。

## 目标

用单个 HTML 文件复刻一台 6.5 L、60° V12 自然吸气发动机 (DOHC · 48气门) 的可交互拆解模型：可运转、可爆炸、可分步拆解、可透视、可系统着色、可导览、可分享、可出声、可导出高清图。

## 交付物（硬性）

1. 仅一个 index.html：内联 CSS 与 ES Module JS，importmap 从 CDN 加载 three@0.161.0 与 addons (OrbitControls、RoundedBoxGeometry、RoomEnvironment、EffectComposer、RenderPass、UnrealBloomPass、OutlinePass、OutputPass、SSAOPass)。importmap 单行写入：

{"imports":{"three":"https://unpkg.com/three@0.161.0/build/three.module.js","three/addons/":"https://unpkg.com/three@0.161.0/examples/jsm/"}}

2. 所有几何体、贴图、声音全部程序化生成：不加载任何外部模型 / 贴图 / HDRI / 音频采样。

3. 双击 file:// 即可运行；控制台 0 报错、0 弃用警告。

4. 输出完整代码（禁止「…」「此处省略」），末尾附 5 行实现说明（零件数 / 三角面 / 已知取舍）。

# 机械规格（数字即法律）

- V 角 60°；缸径 95 × 行程 76.4 mm；缸心距 102；连杆中心距 145；曲轴回转半径 38.2 (scene 单位 cm：9.5 / 7.64 / 10.2 / 14.5 / 3.82)。

- 曲轴：6 道曲拐（每拐并排承载左右两缸）+ 7 道主轴颈 + 扇形配重。

- 12 活塞 + 12 连杆；2 缸盖 + 2 缸垫；4 凸轮轴（每根 12 个桃形凸轮）；48 气门 + 48 弹簧 + 48 挺柱 + 锁片；12 火花塞 + 12 点火线圈。

- 进气：V 谷双稳压腔 + 12 根等长歧管 + 12 个独立节气门 + 12 喷油嘴。

- 排气：2 组 6-into-1 等长头段 + 锥形收集器。

- 正时：双排链 + 5 个链轮 + 张紧器 + 导轨；飞轮 96 齿；离合器；扭转减振皮带轮；水泵；机油泵；干式油底壳；约 125 颗螺栓。

- 点火相位由曲柄几何推导：各缸上止点落在 30° + 60k (720° 循环)；点火顺序 7-5-11-3-9-1-6-12-4-10-2-8，每 60° 一次。

- 活塞运动：s(θ) = r·cosδ + √(L² − r²·sin²δ)，δ = θ + i·60° − 30°·σ（σ = ±1 为左右列）。

- 气门升程：lift = 0.8·exp(−Δ²/0.52)，Δ 为凸轮桃尖方向与挺柱方向夹角；凸轮转速 = 曲轴 / 2。

# 坐标系与镜射

1 scene unit = 1 cm；X = 曲轴轴线，Y 向上，Z 朝观察者；右列绕 X 轴 +30°、左列 −30°。左列必须用反射矩阵 (det = −1)，并翻转「索引」的三角形顺序（在 index.array 内交换三元组），不能交换顶点属性；否则左列镜像件会破面。

# 几何与性能

- 程序化语汇：RoundedBoxGeometry（硬边 0.5–1.5 mm 视觉倒角）、Cylinder / Lathe / 带 bevel 的 Extrude / Tube（贝塞尔曲线）/ 自定义 Helix 弹簧。禁止方块拼凑、禁止纸片感，轴件要有端面倒角/法兰/油封唇口。

- 合并：mergeEntries() 输出索引化几何——带索引图元只平移索引，无索引图元做位置/法线/UV 量化去重；按材质分组。

- 目标规模：30 个可交互零件、≈66 个 Mesh、≈20 万三角面、≈23 万顶点。

- 48 气门用 4 个 InstancedMesh（进/排 × 左右列），每帧仅更新实例矩阵；螺栓用 8 组 InstancedMesh（缸体、主轴承盖、缸盖×2、气门室盖×2、正时盖、油底壳），共享一个螺栓模板。

- 重复小件用 BoxGeometry 替代圆角盒（链节 132、飞轮齿 96、链轮齿 100+）；弹簧降到 72 段 × 5 径向。

# 视觉

- 深色摄影棚：径向渐变背景、地面柔和接触阴影、RoomEnvironment + PMREM 环境、三点布光 + 轮廓光 + 底部补光、ACESFilmicToneMapping（曝光≈1.1）、克制 Bloom (strength 0.15 / radius 0.42 / threshold 1.02)、OutlinePass 描边。

- 材质基调：铸铝 metalness .8 / roughness .5；机加工铝 .88 / .34；锻钢 1.0 / .30；活塞顶亮裙哑双材质；气门镜面钢 + 铜色座圈；排气耐热黑；黑塑料 / 橡胶。强调色只有一种阳极氧化橙 #ff6a2a，且只用于高亮与 UI。

- Canvas 程序化贴图：铸件颗粒、拉丝、地面渐变、V12 铭牌；颜色贴图设 SRGBColorSpace，粗糙度等数据贴图保持 NoColorSpace。

# 交互（全部必须实现）

1. OrbitControls：阻尼 0.055、距离限制、限制极角防穿地；空格切换缓慢自转。

2. 单击零件：橙色描边 + 右侧信息卡（中英文名称 / 所属系统 / 关键规格 / 说明）；悬停蓝色轻描边；点空白取消。

3. 双击零件：飞近聚焦——按该件包围盒取景，大件不后退、小件特写；顶部出现「返回整机」，Esc 或双击空白退出。

4. 爆炸拆解：0–100% 六层延迟错峰（盖板 0 → 进排气/正时盖/油底壳 ~0.05 → 链系/凸轮轴 0.12 → 气门组 0.22 → 缸盖 0.32 → 活塞连杆 0.42 → 曲轴/主轴承盖 0.52）；每件 localT = easeInOut(clamp((t − delay) / 0.45, 0, 1))，方向按左右列法线 (0, .866, ±.5) 与 ±X/±Y；拖动滑块时相机按 1 + 0.5t 后退；回 0 严丝合缝。「拆解演示」按钮 1.9 s 缓动自动往返。

5. 分步拆解 7 步：盖板与外部总成 → 正时链系 → 4 凸轮轴 → 气门组 → 缸盖 + 缸垫 → 活塞连杆 → 曲轴总成；逐件 stepProg 阻尼动画，支持上一步/下一步、PageUp/PageDown、点步骤直接跳转；退出时归位并恢复滑杆读数与相机距离。

6. 透视 (X-ray)：外壳降到 10% 透明、内部结构（曲轴 / 活塞 / 连杆 / 凸轮轴 / 气门 / 链系）保持实体，自动关闭阴影；可与爆炸、分步组合。

7. 系统着色：8 大系统热图（缸体 / 缸盖 / 气门机构 / 进气 / 排气 / 正时 / 曲柄连杆 / 附件）+ 图例 + chips 圆点同步换色；关闭后逐件恢复原始材质。

8. 点火与转速：点火启动后怠速 900 r/min；节气门 0–100% 映射到 8300；0.5 s 时间常数惯性逼近；停机转速自然回落并静音。

9. 仪表盘（右上角）：0–9000 r/min 转速表（红线 7800）、数字读数、功率/扭矩、8 段换挡灯（6400 起亮、7600 面板转红）、功率扭矩曲线（含当前工作点）、1 号缸四冲程示意（活塞位置 + 进排气门升程 + 行程文字）、点火顺序 12 芯片实时高亮与「下一缸」标记。

10. 点火顺序可视化：每 60° 曲轴角点火一次；燃烧室位置辉光精灵 + 一个共享点光源照亮周围铸件；排气脉冲沿 12 条记录的排气头段曲线从排气门传播到收集器 (0.34–0.44 s，sin 包络)；左右列色温略异。事件调度用曲轴绝对角累加、逐帧扫描 (prev, now] 区间，低帧率不漏点火。

11. 声音：见「声音」一节。

12. 导览 7 站：概览 → 正时系统 → 配气机构 → 曲柄连杆机构 → 燃烧与点火 → 进排气系统 → 回归整机；每站是纯数据（机位名 + 爆炸值 + 透视 + 高亮零件 id + 是否运转），切换时统一调用相机机位 / 爆炸目标 / 透视 / 点火，相机 1.15 s 墙钟补间；讲解卡含站号、标题、说明、圆点、上一步/下一步；← → 切换、Esc 退出；导览期间暂停自转并隐藏系统 chips，退出恢复。

13. 分享链接：把状态编码进 URL hash —— e 爆炸百分比、a/p/d 相机球坐标（方位角/极角/半径）、ty 视点高度、x 透视、col 着色、st 分步步数、run/rpm/t 点火与转速节气门、q 画质、sel 选中件；用户交互后每 0.7 s 静默 history.replaceState（首屏演出期间不写）；「分享」按钮强制同步并复制到剪贴板；带 hash 打开时跳过首屏演出直接还原。

14. 高清导出：截图 = 2K（视口 2×），Shift + 截图 = 4K（4×）；临时把 renderer / composer 放大到目标尺寸（按 GPU maxTextureSize 收口）→ 渲染一帧 → 读回像素 → 合成 8.5% 高的深色品牌条（机型铭牌 +「爆炸拆解视图 · 1:1 结构比例」+ 日期 + 右侧 mono 标识）→ 下载 → 恢复画布尺寸与像素比。

15. 键盘：R 点火、X 透视、C 系统着色、S 分步、T 导览、E 拆解演示、M 声音、[ ] 微调拆解、↑↓ 节气门、空格 自转、Shift+截图 4K、Esc 逐级退出（导览 → 聚焦 → 分步 → 取消选中）。

16. 首屏演出：细进度线 → 相机从远端推近 → 发动机由 62% 拆解态在 1.6 s 内分层组装归位 → 缓慢自转，直至首次交互；总时长 ≤3 s。

17. 响应式：≤900 px 控件收纳、仪表盘缩小下移、导览卡改为底部卡、系统面板横向滚动、隐藏次要图形元素。

# 声音（WebAudio，脉冲串模型，无采样）

- 点火频率 f0 = rpm / 10 Hz（V12 四冲程：每 720° 点火 12 次；怠速 900 → 90 Hz，红线 8300 → 830 Hz）。

- 排气压力脉冲：时域构造单个脉冲 rise·e^(−u·decay)（rise 0.035、decay 9）→ 傅里叶系数 → PeriodicWave；双振荡器 ±5 cents 失谐。

- 非对称过载：tanh(2.6x) + 0.18x²·sgn(x)（4× 过采样），驱动量随负荷与节气门上升。

- 排气管共振：三级 peaking（Q 5.5 / 4.5 / 3.5，增益 10 / 8 / 6 dB），中心频率 92 + 0.012rpm、230 + 0.055rpm、700 + 0.16rpm；低通 1050 + 0.62rpm + 1400·节气门。

- 脉冲同步噪声层：排气湍流（带通 180 + 0.09rpm，被同频窄脉冲调幅）、高频撕裂（1.5 kHz 起，同调幅）、进气（320 Hz 起随节气门）、机械气门（高通 2.8 kHz，2×f0 调幅）。

- 点火爆震层：更短的脉冲型线（decay 26）单独混入；半阶低频正弦 f0/2，增益 0.055·(1 − load)，只给低转。

- 有机抖动：低速噪声调制音高（±7 cents）与音量；总线：Gain → 85 Hz low shelf → 2.4 kHz presence → 限幅器 → Analyser → 输出，6% 卷积混响；音量按负荷修正 0.74 + 0.26·load。

- 试听：用 OfflineAudioContext 复用同一节点图离线渲染 4 s WAV 下载（未点火默认 2400 r/min）；暴露 renderAudioBase64(seconds, {rpm, throttle}) 与 audioSpectrum()（f0、12 阶谐波峰、频谱质心）。
