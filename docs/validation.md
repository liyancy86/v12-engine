# 运动学与碰撞检查：证据到哪一步

这份文档记录"哪些结论有可复现的证据，哪些只是一次性检查的结果"。写在前面：**这是演示模型，不是校核工具。**

## 1. 运动学：可复算的部分

活塞位置 `s(θ) = r·cosδ + √(L² − r²sin²δ)`，`δ = θ + i·60° − 30°σ`。

- `r = 3.82` cm（行程 7.64 的一半），`L = 14.5` cm
- `θ`：曲轴自零位的转角，正向绕 +X 轴，单位度
- `i ∈ {0..5}`：**列内几何序号**（不是缸号，不是点火顺序位次）
- `σ = ±1`：右列 +1 / 左列 −1
- `s`：从曲轴轴线沿缸轴向上量到活塞销中心，单位 cm
- 上止点 `s = 18.32`、下止点 `s = 10.68`、行程 `7.64`

可复算的检查：任取一个 `θ`，把 12 组 `(side, i)` 代进去，`s` 的值域必须落在 `[10.68, 18.32]`；且每组在 720° 内恰好出现两次 18.32（压缩与排气上止点各一次）和两次 10.68。

连杆姿态：显式正交基 `makeBasis(+X 贴曲拐销轴向, +Y 杆身方向, Z=叉积)`，行列式 +1，无反射。大头环单独 `quaternion.identity()`。

内置自检（代码注释里的历史记录）：全转角实测小头位置与活塞销偏差 0.000、杆长恒为 14.5。这是一次性数值检查，脚本未入仓。

## 2. 配气相位：已确认不对齐

气门相位取自需求规格点火顺序的位次（`CYL_PHASE[n] = index·60`），活塞位置取自几何序号。两套编号不同源，导致 12 个缸的"气门峰相对本缸压缩上止点的偏差"各不相同 —— 详见主 README §5.1 的偏差表与 6 行复算脚本。

判据是干净的：自洽模型里 12 缸偏差应为同一常数，实测是 10 个不同值。

**这条是当前最实质的缺陷，未修。**

## 3. 碰撞检查：结论的范围

做法：对每个三角面取面内采样点，变换进被检零件的局部坐标系，做实体包含判定，跑 8 个曲轴转角。

| 零件对 | 当时结果 |
|---|---|
| 曲轴 vs 连杆 / 活塞 | 0 命中 |
| 同曲拐销配对的两根连杆 | 0 命中 |
| 活塞 vs 缸套 | 36 / 12000 采样点，归因未定 |

**必须说清的三件事：**

1. **"0 命中"不是"无穿模"证明。** 面内有限采样会漏掉窄小相交区；只跑 8 个角度也覆盖不到其余运动区间。准确表述是"指定 8 个姿态、指定采样规则下未检出"。
2. **原始探针脚本没有入仓。** 上面的数字不可由仓库独立复现。这是缺陷，不是省略。
3. **36 / 12000 没有定论。** 当时写作"阈值边界效应，非几何错误"，但没定义 12000 的统计对象、命中深度、预期装配间隙和容差扫描。把它当"已验证通过"是错的 —— 它更可能反映"活塞与缸套之间本来就是零间隙示意配合"，而不是真实装配校核。

## 4. 采样点定义（补评审要求）

一个三角形只有一个几何重心。当时说的"3 个重心点"应读作**三个由重心坐标定义的内部采样点**，加上三条边的中点，共 6 点/三角面。重心坐标与命中容差没有留档。

"实体包含判定"用射线奇偶法，对开放曲面（本模型里的敞口筒，如活塞裙、缸套）在奇偶判定上会失真 —— 这是这套方法的结构性弱点。

## 5. 要做出可信结论需要什么

- 把探针脚本入仓，含采样点重心坐标、容差、零件对清单、运行命令
- 角度扫描（例如每 5° 一次，共 144 个姿态）而不是 8 个
- 双向测试（A 在 B 内 + B 在 A 内）
- 三角形-三角形相交判定，替代采样点包含判定
- 报告最大侵入深度与位置，而不是只报命中计数
