# 渲染：火焰、透明、镜像

这份文档记渲染上几个被反复问到的地方，结论都限定在具体配置下。

## 1. 火焰为什么只在透视模式显示

目标形态是"被不透明件遮挡、透过透明件可见"。当前单通道透明排序方案下没做到，两组同机位对照：

| 配置 | 结果 |
|---|---|
| `depthTest: true` + 非透视 | 整机视图一点火光都没有。缸套虽不写深度，但缸盖、气门室盖、排气头段是实心的，把燃烧室包死 |
| `depthTest: true` + 透视 | 火被压成一层淡桃子色。气门、凸轮、弹簧、活塞始终是实心件，正好挡在火前面 |

所以选 `depthTest: false` + `renderOrder: 8` 画在壳上面，代价是某些角度像浮在壳体表面。分层渲染、深度预处理、选择性遮挡、剖切都能提供不同取舍，只是没做。**这是当前选择，不是"只能如此"。**

## 2. 火焰体是圆柱形燃烧空间示意

`CylinderGeometry(1, 1, 1, 48, 10, false)` 的单层带端盖筒，半径 = 缸套内壁 − 0.23，高度每帧按"上端顶死缸盖、下端跟活塞冠"算。

为可见性钳了显示下限 0.55（按 1 unit = 1 cm 即 5.5 mm）。这个下限**会超出某些时刻的真实几何间隙** —— 它是视觉效果，不是燃烧室尺寸。圆柱也不代表真实燃烧室含气门凹腔的形状。

真实燃烧室高度在压缩上止点附近只剩约 1 mm 量级，那种尺寸下火焰在屏幕上不可见，所以必须做一个显示下限。

## 3. 单层还是双层

第一版套了内层并开 `DoubleSide`，结果半透明三角面的前后壁互相叠，接缝全露、整团火像切面宝石。

`DoubleSide` 的直接含义是**允许背面参与渲染**；具体绘制次数还与 Three.js 版本、透明材质、`forceSinglePass` 等设置有关。这里的实际问题是透明双面渲染增加了叠加层数与排序冲突，不能简化成"前后壁各画一遍"。

现在：单层几何 + `FrontSide` + `depthWrite: false`。

## 4. 噪声与色调映射

噪声是脚本逐像素算的可平铺 fBm，四倍频。**不能用 canvas 放大** —— 出来是一块块方格，贴到缸里像一床被子。三层不同尺度、不同流向的滚动叠出翻卷感，U 偏移跟着高度走形成筒内螺旋。

温度→颜色：余烬 → 暗红 → 橙 → 黄 → 白热。白热只给湍流最旺的局部，亮度乘子压在 0.86~1.16。

关于 ACES：**不存在"超过 1.0 就变黄白"的通用硬阈值。** 准确定表述是"高亮经色调映射后趋于去饱和"。产物取决于 RGB 比例、曝光、色彩空间和后处理链。这里的观察只在这个材质、这个曝光、这套后处理下成立，换个配置要重新看。

## 5. 左列不是几何镜像

代码注释与旧版 README 都说过"缸列局部 z 乘 side 做镜像"，实际实现是：

```js
const bk = (side, geo, x = 0, y = 0, z = 0) => {
  geo.translate(x, y, z);
  geo.rotateX(side * BANK);
  return geo;
};
```

**`bk()` 里没有任何取反。** 它只做"平移到缸列局部坐标 + 绕 X 轴 ±30°"。

镜像发生在**调用点的 z 参数**上，例如 `rbox(1.1, 11.0, 0.9, 0.2), (i-3)*9.2, 13.4, 7.6*side` —— 右列 `z=+7.6`、左列 `z=−7.6`。

这意味着：

- 作用对象是**参数 / 点坐标**，不是成品顶点数组，也不是物体变换矩阵
- 所有部件都是"按点重新生成几何"（`Tube` 走逐点 CatmullRom，圆柱走 `cylZ`），所以**不存在顶点级反射与绕序翻转**
- 最终每个部件的变换仍是纯旋转（行列式 +1）加平移

能验证到的：两列进气道口都朝 V 谷（z ∈ ±7.35）、排气道口都朝缸盖外侧（z = ±19.0）。这是**位置对称**，不是"完整几何镜像等价"的证明；部件自身的法线与姿态在轴对称件上天然对称，对非轴对称件（贝塞尔歧管路径）靠逐点重算保证。

## 6. 材质上的两个坑

- **链轮盘面必须单独给 `metalness: 0.5`**，否则高金属度平面只镜射环境暗区，渲成纯黑圆饼
- **缸套做成敞口筒（`cylY(..., open=true)`）**并把上沿抬到缸列局部 y = 20.95：原先 15.4 长、带上下端面的实心圆柱会在 y = 20.70 处用一片圆盘横切过活塞冠 0.15。同一类错误还删掉了一块 0.9 厚、包在缸体内部的"机加工顶面"板 —— 它与主体同指 `blockGlass`，只让顶面半透明度叠加到约 0.94，活塞冠穿过时看着像被切掉一截
- **上口密封环内孔由 4.62 放大到 4.80**（活塞裙最大半径 4.73，缸径半径 4.75）：原尺寸每转到上止点啃穿环 0.11
